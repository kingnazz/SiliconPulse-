Local AI

Is my model actually using the GPU?

SiliconPulse finds the runners on your Mac and asks them, on 127.0.0.1 only, what they are doing.

  • oMLX, Ollama, LM Studio, llama.cpp, MLX and any OpenAI-compatible server
  • Loaded model, model memory, context and GPU offload, as the runner reports them
  • The runner's own CPU, memory and GPU time, from its process tree
  • Tokens per second only when the runner really publishes it
  • System GPU is always the whole Mac, never credited to a model

Shown: a real oMLX server serving Qwen2.5 0.5B.

Honest numbers

No invented values.

macOS does not expose everything. When something is measured, SiliconPulse shows it plainly; when it is inferred, it says so; when it is not available, it says why. Hover any value to see where it comes from.

Install

  1. Download SiliconPulse.dmg.
  2. Open it and drag SiliconPulse to Applications.
  3. Open SiliconPulse from Applications. It lives in your menu bar.

If macOS says it could not verify that SiliconPulse is free of malware, open System Settings › Privacy & Security and click Open Anyway. You only need to do this once; the release notes say when a build is notarized.
